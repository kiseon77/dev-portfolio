아톰릭스랩에 인턴으로 입사하여 2달간 진행한 인턴 과제입니다. <br/>
사용자가 슬롯머신 게임에서 당첨 시 다채로운 애니메이션과 물리 기반의 효과를 체험하도록 구현

![슬롯머신 당첨 애니메이션](/projects/pgaslot.gif)

## 담당

- 총 3팀의 미니게임 디자인 작업
- 슬롯머신 기획, 디자인, 프론트엔드 구현

## 기술 스택

TypeScript, React, Sass, Zustand, GSAP

## 주요기능

- **GSAP 타임라인 기반 순차 당첨 연출** : 시퀀스를 활용해 디테일하게 구현
- **Matter.js 활용 2D 물리 렌더링** : 당첨 시, 재화 애니메이션
- **CSS steps() 기반 프레임 애니메이션** : 스프라이트 애니메이션
