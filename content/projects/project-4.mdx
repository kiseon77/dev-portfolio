아톰릭스랩에서 계약직으로 넘어와 담당하게된 프로젝트입니다. <br/>
AI 캐릭터와 게임을 즐길 수 있는 인터랙티브 웹 게임

## 담당

- ComfyUI를 활용한 이미지 생성
- 캐릭터 생성 파트 UI/UX, 프론트엔드
- 룰렛 미니게임 프론트엔드
- 상점 파트 프론트엔드
- 이벤트/퀘스트 파트 기획 및 프론트엔드

## 기술 스택

TypeScript, Svelte, Tailwind V4, GSAP

## 주요기능

- **AI 이미지 워크플로우 구축** : ComfyUI 노드 기반 이미지 생성 파이프라인을 통해 Web3 게임 핵심 에셋인 AI 캐릭터 생성
- **AI 이미지 생성 파이프라인 자동화 (Python + ComfyUI API)** : 수백개의 프롬프트 json 리스트를 Python과 ComfyUI API를 연동한 무인 배치(Batch) 자동화 스크립트 구축하여 이미지 대량 생성 자동화
- **동적 SVG/GSAP 보상형 룰렛 구현** : 삼각함수 기반 SVG 섹터 동적 좌표 계산 및 GSAP 회전 연출 구현, 아이템/확률 변경에 대응 가능한 모듈화 설계
